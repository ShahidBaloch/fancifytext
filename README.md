# FancifyText

**[fancifytext.com](https://fancifytext.com)** — free Unicode fancy text and font generator.

Type once, browse styles (bold, cursive, bubble, small caps, Discord colors, kaomoji, emoji combos), and copy-paste into Instagram, TikTok, Discord, WhatsApp, LinkedIn, and games. Everything runs in the browser; no account required.

## What you can do

- Fancy text hub and style search
- Platform tools: Instagram, TikTok, Discord, WhatsApp, LinkedIn, Roblox, and more
- Name generators for gaming and social bios
- Kaomoji, emoji combos, symbols, and text art collections
- Case converter, invisible character, unformat back to plain text

## Tech (high level)

- Next.js, TypeScript, Tailwind CSS
- Client-side Unicode transforms (no font files installed on the device)
